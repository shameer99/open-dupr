Open DUPR
Project retired

Thank you for playing.

I built Open DUPR to make checking ratings and recording matches faster, simpler, and free from ads and upsells.

Keeping up with DUPR’s API and authentication changes now takes more time than I can give this project. The move to a server-side proxy also reduced some of the simplicity that made it worthwhile. Meanwhile, the official app has improved in several areas.

I still wish the official experience had fewer subscription prompts and made the option to skip them more obvious. But I can no longer give Open DUPR the maintenance it needs, so it’s time to retire it.

Thanks to everyone who used it, shared feedback, or contributed.
— Shameer

Your account, ratings, and match records remain with DUPR. This retirement does not delete them. Open DUPR is an independent project and is not affiliated with DUPR.
